# CSV Metadata Format for Timeline Visualization

SOFA can display a **timeline bar** under the video that highlights frames based on a metadata CSV file. This document describes the expected CSV schema and how it integrates with the UI.

## 1. Purpose

The metadata CSV provides **per-frame** information used to color the timeline:

- **Gray**: “normal” frames (e.g. no or low activity).
- **Red**: “suspicious” or noteworthy frames (e.g. face detected, motion, or custom flag).

This helps you quickly see where to mark segments for removal when exporting clips.

## 2. File Location and Naming

- The CSV file is looked up next to the **currently loaded video**.
- Naming convention: same base name as the video, with extension `.csv`.

Examples:

| Video file           | Metadata CSV          |
|----------------------|------------------------|
| `~/videos/meeting.mp4` | `~/videos/meeting.csv` |
| `document.avi`       | `document.csv`         |

Implementation detail: in SOFA the path is built as  
`{video path with extension removed}.csv`  
(e.g. in `video_window.py`: `self.fileName.rsplit('.', 1)[0] + '.csv'`).

## 3. CSV Schema

### Required columns

| Column     | Type   | Description |
|------------|--------|-------------|
| `frame_num` | integer | Frame index (0-based or 1-based; must be consistent). Used to sort and align with the timeline. |
| `diff`      | numeric | Value used to decide timeline color. See below. |

### The `diff` field

- **Meaning**: “Difference” or “anomaly” indicator for that frame. Exact semantics are up to whoever generates the CSV (e.g. face count, motion score, binary flag).
- **Usage in SOFA**:
  - `diff == 0` → frame is drawn **gray** on the timeline (normal).
  - `diff != 0` → frame is drawn **red** (suspicious / needs attention).

For the optional “yellow” mode (two algorithms):

- `diff == 0` → gray  
- `diff == 1` → red  
- `diff == 2` → yellow  

So: one numeric column drives the color; the name `diff` is fixed in the code.

### Optional columns

You can add extra columns (e.g. `face_count`, `confidence`, `timestamp`) for your own tooling. SOFA only reads `frame_num` and `diff` for the timeline.

### Example CSV

```csv
frame_num,diff
0,0
1,0
2,1
3,1
4,0
5,0
```

- Frames 0, 1, 4, 5 → gray.  
- Frames 2, 3 → red.

Another example with extra columns (SOFA still only uses `frame_num` and `diff`):

```csv
frame_num,diff,face_count,notes
0,0,0,no face
1,0,0,no face
2,1,1,face detected
3,1,1,face detected
4,0,0,no face
```

## 4. Integration with Timeline Visualization

- **Widget**: `HlightSliderTipsWidget` in `src/bad_clips_slider.py`.
- **Data loading**: `get_metadata_colors()` in `src/utils.py`:
  - Reads the CSV with pandas.
  - Sorts by `frame_num`.
  - Returns the `diff` column as a sequence (one value per frame).
- **Drawing**: For each index (frame), the widget uses `diff` to choose pen/brush color (gray vs red, or gray/red/yellow in yellow mode).
- **Range**: The length of the `diff` sequence sets the timeline length (number of “steps”). It should match the number of frames you want to represent (e.g. one row per video frame, or one per group of frames if you downsample).

If the CSV is missing, invalid, or has no `frame_num`/`diff`, the timeline falls back to an empty state (no colored segments).

## 5. Generating Metadata

Currently SOFA does **not** create this CSV automatically. You can:

- **External script**: Run your own face detector or motion detector and write a CSV with `frame_num` and `diff`.
- **Future SOFA feature**: The application could optionally write this CSV during “pre process” (face detection), e.g. setting `diff = face_count` or `diff = 1` when at least one face is detected.

Example (pseudo-code) for “face count as diff”:

```python
# For each video frame:
#   run face detector
#   diff = number of faces (or 1 if any face, 0 otherwise)
#   write row: frame_num, diff
```

Consistent `frame_num` (e.g. 0 to N-1 for N frames) and a single `diff` column are enough for SOFA’s timeline.

## 6. Summary

| Item | Detail |
|------|--------|
| **File** | `{video_basename}.csv` next to the video file |
| **Required columns** | `frame_num`, `diff` |
| **Color rule** | `diff == 0` → gray; `diff != 0` → red (and optionally `diff == 2` → yellow) |
| **Used by** | `get_metadata_colors()` → `HlightSliderTipsWidget` |
| **Generated by** | External script or (in the future) SOFA during preprocessing |
